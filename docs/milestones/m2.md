# Adoption

## Goal

Someone new to Peal can adopt it without reading the design first: the README explains
Peal in one screen, `/peal:next` suggests the next thing worth adopting, `peal doctor`
says what is broken and how to fix it, and a project with its own task-file process
migrates onto Peal.

## Acceptance criteria

- `peal doctor` names each broken case with one fix, and exits non-zero on any (0036).
- `/peal:next` suggests different, fitting next steps on projects in different states,
  and none once everything is set up (0030).
- `peal migrate headers` and `peal migrate milestones` convert the reference project's
  tasks and milestones, and `peal list` and `peal board` agree with its own (0014).
- A reader new to Peal gets from the README to a first worked task with the README and
  the getting-started guide alone, and every example in the docs is exercised by a
  harness (0031).
