# Cheaper tasks

## Goal

A task costs fewer turns, tokens and minutes: harnesses under one awk and a parallel test-all, the macOS job sharded, four to six fewer turns per task, a planner that reads sections and the issues a task cites and asks only what is the human's, small pull requests outside the boundary tiers that merge by themselves, no stray claim or branch left behind.

## Acceptance criteria

- The implementer's brief says to run one harness under one awk, the main session runs
  none, and a representative harness builds its fixture once (0185); `tools/test-all.sh
  -j 4` gives the serial run's result in parallel (0190).
- The macOS job's longest shard is under 13 minutes on a code pull request (0186).
- A session of the same size as before needs at least four fewer tool calls (0187); the
  reviewer's brief holds the last milestone review's Outcome and `close finish` runs
  shellcheck only on changed files (0189).
- A `context:` entry names a section and the brief says so (0188); the planner's brief
  carries the issues and pull requests the task cites, quoted (0135); the shared helpers
  run in half the processes (0156).
- Every guard path `docs/security.md` names is in a merge tier (0162), and a task pull
  request outside the tiers merges by itself once CI and the security review pass, with
  no grace (0219).
- A planned task asks at most four human questions and records the count (0218); a claim
  from a subagent outside a fixture is refused (0220); the autosave re-pushes no merged
  or done branch (0221).
- `peal record --round` keeps the round on the claim and the fourth round is refused
  with the split-or-defer question (0199); the hostile harness flags a silent status-2
  run (0165); a locked config prints no raw lock error at hook install (0169).
