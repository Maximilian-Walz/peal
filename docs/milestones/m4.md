# Main decides

## Goal

What runs on the human's machine is chosen by the main branch, not by whatever branch is
checked out: the git gates' settings and the close checks are read from main's config,
and a launcher that differs from the installed plugin's is reported.

## Acceptance criteria

- A branch that changes `checks.commit`, `main` or `checks.close` in its own
  `.peal/config.yml` does not change what the gates or close run on it (0091, 0089), and
  `worktree-setup` runs from main's config (0170).
- `peal check` (or SessionStart) warns when the committed launcher differs from the
  installed one (0088), and doctor's launcher remedy never runs the `.peal/peal` it
  flagged (0205).
- `docs/security.md` says a Bash-call gate cannot hold against the session's own
  environment, `peal doctor` reports branch protection on main, and each prefix, wrapper
  and refspec form of the review's list is a refused case (0181).
- The threat model says gh with the user's token can merge or write contents directly
  and what closes it (0182), and covers Claude Code configuration changed on a task
  branch, with the SessionStart report and the close NOTE (0183).
- The config loader refuses an invalid `storage.issues.repo`, `main`, `remote` or
  `branch-prefix`, the hostile harness covers them, and the low findings each have a
  test or a documented limit (0120, 0184).
- An unknown command names the running Peal and its version (0136); the two version
  comparators are pinned together (0125); the reviewer proposes the Security line's
  boundary (0158).
- `docs/security.md` says so, with the tests.
