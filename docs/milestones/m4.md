# Main decides

## Goal

What runs on the human's machine is chosen by the main branch, not by whatever branch is
checked out: the git gates' settings and the close checks are read from main's config,
and a launcher that differs from the installed plugin's is reported.

## Acceptance criteria

- A branch that changes `checks.commit`, `main` or `checks.close` in its own
  `.peal/config.yml` does not change what the gates or close run on it (0091, 0089).
- `peal check` (or SessionStart) warns when the committed launcher differs from the
  installed one (0088).
- `docs/security.md` says so, with the tests.
