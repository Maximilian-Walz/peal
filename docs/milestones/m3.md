# Smooth sessions

## Goal

A session that works a task, alone or under a control plane, gets through claim, commit
and close without workarounds: close waits for CI without spending the human's GitHub
budget, survives a sandbox that blocks config writes or hides files, and turns its own
draft pull request ready; `peal commit` takes the arguments sessions give it and leaves
no stray stage; filed text keeps its origin on both storages; and what Peal shows the
human (pull request bodies, questions) is short enough to be read.

## Acceptance criteria

- Under Belfry, close waits with `wait_ci`; outside it, `peal close wait` as before (0067).
- `close finish` succeeds, and `close verify`/`wait` work, in a sandbox that blocks
  `.git/config` writes (0101), and marks an open draft ready (0099); lint prints nothing
  about files it cannot open (0100).
- `peal commit -m SUBJECT PATH` commits, `--help` prints usage, and a refused commit
  leaves the index as it was (0102, 0093).
- `--origin outsider` survives on the issues storage, and this repository passes it (0094,
  0095).
- A pull request body opens with a summary for the person who merges (0068).
