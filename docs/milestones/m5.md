# Human tasks and kinds

## Goal

A wait for the human is a task of its own, with a start (a brief) and a finish that
leaves nothing in the repository, filed by the commands that find it; and tasks carry a
kind from the project's config that close and release use.

## Acceptance criteria

- `/peal:brief` and `peal done` start and finish a human task (0043).
- `/peal:idea`, `/peal:defer` and `/peal:split` file a human task where the work is the
  human's, and the waiting task depends on it (0044).
- A task's `kind` comes from the config, shows as a pill, maps to labels, and orders the
  release notes (0060).
