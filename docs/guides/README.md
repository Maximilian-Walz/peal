# Guides

One short page per workflow, each with an example the docs check runs. They say when and
how to do a thing; the [reference](../reference/README.md) says exactly what each command
takes and prints, and [the design](../design.md) why. The first task is in
[getting started](../getting-started.md); the guides begin where it ends.

- [Working a task](working-a-task.md): plan, build, review and close, and what to do when a
  step fails or the session stops.
- [The backlog](backlog.md): file, split, defer, retire and revise tasks, and read what is
  waiting.
- [Milestones](milestones.md): the goals tasks belong to, their states and their review.
- [Running under Belfry](belfry.md): the same commands, run unattended.
- [Releases](releases.md): a tagged version from the tasks finished since the last one.

The words are those of the [reference](../reference/README.md#words).
